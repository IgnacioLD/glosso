# Textbook (learner-dictionary) phonetics

The IPA the learner **sees** must be the one they recognise: a British learner's
dictionary (Oxford Learner's, Cambridge, Longman). The owner's words: *"tiene que
ser como la de los libros de texto para que sea mas facil"*, *"una IPA que puedan
entender"*.

The product keeps **two representations** and they do not have to match:

| | what | where | used by |
| --- | --- | --- | --- |
| **internal** | the reference IPA | `content.db` `ipa` | the scorer, as `expectedIpa` |
| **presentation** | the textbook form | `displayIpa` on each item | the app, when the learner turns phonetics on |

The internal form only has to **score** well; the presentation form only has to be
**understood**. `textbook_ipa.py` builds the presentation form and never touches
`ipa`, so scoring is byte-for-byte unchanged.

## Where the display form comes from

It is derived from the espeak-ng `en-gb` phonemization (`data/en_gb_ipa.tsv`,
written by `en_gb_reference.py`), the same build-time tool as `phonemize.py`.
espeak already gives a British, non-rhotic reading with length marks and stress;
the tool only rewrites the symbols where the learner's dictionary differs:

| espeak | textbook | why |
| --- | --- | --- |
| `ɹ` | `r` | dictionaries print /r/, not the IPA turned r |
| `ɛ` | `e` | DRESS is /e/ (bed /bed/) |
| `a` | `æ` | TRAP is /æ/ (cat /kæt/); /a/ stays inside `aɪ`/`aʊ` |
| `ɐ` | `ə` | unstressed central vowel folded into the schwa the learner expects |
| `i` (+ə) | `ɪ` | NEAR is /ɪə/ (near /nɪə/); the long /iːə/ of "Leo" stays |
| `n̩` | `n` | syllabic n (wasn't) |

Everything else is already the dictionary convention: /iː ɪ ɒ ɔː ʊ uː ʌ ɑː ɜː ə/,
the diphthongs /eɪ aɪ ɔɪ əʊ aʊ ɪə eə ʊə/, the stress marks `ˈ` `ˌ` and the length
mark `ː`. Decisions, in the spirit of the owner's "familiarity over
exhaustiveness": the word-final optional `/r/` ("water" /ˈwɔːtə(r)/) is **not**
added, and NOTATION follows Oxford/Cambridge even where it simplifies the phonetic
reality (dictionaries do this on purpose). Where two symbols are both defensible,
the tool picks the one a learner finds in their dictionary.

## Run

Same environment as `en_gb_reference.py` (plain Python for the rewrite; the
sample also needs the espeak backend that `phonemize.py` sets up - see that
module's docstring).

```sh
# Regenerate the display data for the whole catalogue.
python textbook_ipa.py --reference data/en_gb_ipa.tsv --out-tsv data/en_gb_display.tsv

# The owner's sample table.
python textbook_ipa.py --sample data/en_gb_display_sample.tsv --cmudict /path/to/cmudict.dict
```

`data/en_gb_display.tsv` is `key kind internal_ipa display_ipa`, one row per
scorable item, for review and as the input of the apply steps below.

## Apply to the content

`--apply` never edits the source in place: it writes a **copy** of `content.db`
with `displayIpa` added next to each item's `ipa`.

```sh
python textbook_ipa.py --db .../content.db --apply /tmp/content.display.db
```

**Durable path.** `content.db` is rebuilt from the published banks
(`tools/content/pipeline.py`), so a field added only to the DB is lost on the next
publish. Stamp the banks instead, then rebuild normally. Stamp both the authored
banks (so a future `publishContent` keeps the field) and the published ones:

```sh
python textbook_ipa.py --banks <glosso-data>/content/en
python textbook_ipa.py --banks <glosso-data>/content/en/dist
```

The write is a surgical text edit after each `"ipa"` field, so a hand-authored
compact dialogue line or a kotlinx 4-space bank is not reformatted. The command
prints, per folder, how many fields it wrote and how many items had no display
form (a gap is reported, never left silent).

Applied to the shipped content in `glosso-data` (PR #26): 2122 fields, 0 gaps
(DRILL 417, WORD 812, DIALOGUE 805 turns, STORY 88). The 65 ARTICLE items have no
`ipa` field at all (the app does not show article phonetics), so they carry no
`displayIpa`.

The app reads `displayIpa` and falls back to `ipa` when it is empty, so the field
can ship item by item with no app release.

## Tests

```sh
python3 tools/content/textbook_ipa_test.py
```

Pins the notation rewrite (DRESS/TRAP/NEAR/schwa/rhotic/syllabic-n), the
invariance of the dictionary vowels and the stress/length marks, the owner's six
cases, and (when the data files are present) that every row of
`data/en_gb_display.tsv` is the textbook rewrite of the reference and carries no
espeak-only symbol.
